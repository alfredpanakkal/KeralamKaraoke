# Screenshots to capture

The README references three images. Capture them once and save here with these exact names.

| File | Shows | When |
|---|---|---|
| `hero_karaoke_progress.png` | Progress bar, status caption and ETA mid-separation | Karaoke mode, while running |
| `karaoke_result.png` | Audio player + Download button | Karaoke mode, after it finishes |
| `stems_result.png` | One player + Download per stem (vocals/drums/bass/other) | Stems mode, after it finishes |

Recipe (Windows):

1. Double-click `launch_karaoke.bat` and wait for the browser to open.
2. Upload any short song (under 30 s) and start a Karaoke separation.
3. While the progress bar is running: press `Win+Shift+S`, drag the selection over the progress area, paste into Paint, save as `hero_karaoke_progress.png` in this folder.
4. When it finishes: capture the player + download row as `karaoke_result.png`.
5. Switch to **Stems** mode, click **Generate**, wait, capture the four players as `stems_result.png`.
